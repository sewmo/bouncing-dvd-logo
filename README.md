# Description
A nostalgic recreation of the bouncing DVD logo in OpenGL. 

# Dependencies
**OpenGL** - The Open Graphics Library managed by Khronos Group, for graphics rendering.
**stb_image** - Single header file library for image loading.
**GLFW** - Graphics Library Framework, for managing the window and user input.
**GLAD** - OpenGL Loader Generator for loading function pointers.

# Installation
Download the .ZIP file, extract it, and run the 'main.exe' executable.
